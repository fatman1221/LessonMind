# AI辅助教师备课系统

## 项目简介

AI辅助教师备课系统采用"三模块一核心"的整体架构，覆盖教师备课全流程。系统基于通义千问大模型，为教师提供智能化的备课辅助服务。

## 系统架构

### 三模块一核心

1. **教师设计子系统**: 支持教师输入"学科+学段+课时主题+教学目标"，自动生成含教学环节(导入、讲授、互动、总结)、时间分配、预期成果及3个以上互动设计的完整教学设计，支持在线编辑与Word格式导出。

2. **多媒体资源子系统**: 基于教学设计知识点，自动生成图片(如数学函数示意图、语文课文场景图)、PPT课件(匹配教学环节)支持自定义风格与格式。

3. **学情分析与题库子系统**: 导入学生历史数据(作业成绩、学习行为)，通过算法评估预备知识掌握水平(准确率≥85%)，推荐个性化预习资料;同时基于知识点生成选择/填空/简答题，支持批量导出与难度调整。

## 技术栈

- **前端**: Vue 3 + Element Plus + Vite
- **后端**: Python FastAPI + SQLAlchemy
- **数据库**: MySQL
- **AI模型**: 通义千问 (DashScope)
- **缓存**: Redis (可选)
- **文档生成**: python-docx, python-pptx

## 快速开始

### 环境要求

- Python 3.8+
- Node.js 16+
- MySQL 5.7+
- Redis 6.0+ (可选)

### 后端启动

1. 安装依赖
```bash
cd backend
pip install -r requirements.txt
```

2. 配置环境变量
```bash
cp .env.example .env
# 编辑 .env 文件，配置数据库和API密钥
```

3. 创建数据库
```bash
mysql -u root -p < ../database/init.sql
```

4. 启动服务
```bash
python main.py
```

后端服务运行在 `http://localhost:8000`

### 前端启动

1. 安装依赖
```bash
cd frontend
npm install
```

2. 启动开发服务器
```bash
npm run dev
```

前端服务运行在 `http://localhost:3000`

## 核心功能说明

### 1. 教学设计生成

输入学科、学段、课时主题和教学目标，系统自动生成包含以下内容的完整教学设计：
- 导入环节（5分钟）
- 讲授环节（25分钟）
- 互动环节（10分钟，至少3个互动设计）
- 总结环节（5分钟）
- 预期成果

### 2. 多媒体资源生成

- **图片生成**: 基于知识点自动生成教学图片描述（可对接Stable Diffusion等图片生成服务）
- **PPT生成**: 根据教学设计自动生成PPT课件，支持多种风格

### 3. 学情分析

- 基于决策树算法构建"知识掌握度-学习能力-学习习惯"三维评估体系
- 准确率≥85%
- 提供个性化学习建议

### 4. 题库生成

- 支持选择题、填空题、简答题
- 自动生成答案和解析
- 支持批量导出
