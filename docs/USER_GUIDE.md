# 用户使用指南

## 系统简介

AI辅助教师备课系统是一款基于通义千问大模型的智能备课工具，帮助教师快速生成教学设计、多媒体资源和进行学情分析。

## 功能模块

### 1. AI对话

- **功能说明**: 与AI助手进行对话，获取教学建议和答疑
- **使用方法**:
  1. 在输入框中输入问题
  2. 点击"发送"按钮或按 Ctrl+Enter
  3. 查看AI回复
  4. 可以点击"清空"清除对话历史

### 2. 教学设计

- **功能说明**: 自动生成完整的教学设计方案
- **使用步骤**:
  1. 点击"新建教学设计"
  2. 填写学科、学段、课时主题、教学目标
  3. 点击"生成"按钮
  4. 等待AI生成教学设计（约1-2分钟）
  5. 查看生成的教学设计，可以导出为Word文档

**教学设计包含**:
- 导入环节（5分钟）
- 讲授环节（25分钟）
- 互动环节（10分钟，至少3个互动设计）
- 总结环节（5分钟）
- 预期成果

### 3. 多媒体资源

#### 图片生成
1. 选择已创建的教学设计
2. 输入知识点
3. 点击"生成图片"
4. 下载生成的图片

#### PPT生成
1. 选择已创建的教学设计
2. 选择PPT风格（默认/简约/商务）
3. 点击"生成PPT"
4. 下载生成的PPT课件

### 4. 学情分析

#### 导入学生数据
1. 点击"导入学生数据"
2. 填写学生基本信息
3. 输入作业成绩（格式：作业1:85,作业2:90）
4. 输入学习行为数据（JSON格式）
5. 输入知识点掌握情况（JSON格式）
6. 点击"导入"

#### 学情分析
1. 输入学生ID
2. 点击"开始分析"
3. 查看分析结果：
   - 掌握水平
   - 掌握度评分
   - 学习能力评分
   - 学习习惯评分
   - 学习建议

#### 题库生成
1. 选择学科
2. 输入知识点
3. 选择题目类型（选择题/填空题/简答题）
4. 设置题目数量
5. 点击"生成题目"
6. 查看生成的题目，包含答案和解析

## 使用技巧

1. **教学设计优化**: 生成后可以手动编辑内容，系统会保存修改
2. **批量操作**: 可以一次性生成多个教学设计，然后批量导出
3. **资源关联**: 多媒体资源会自动关联到对应的教学设计
4. **数据导入**: 建议先导入足够的学生数据（至少10条）再训练模型，提高分析准确率

## 常见问题

### Q: 教学设计生成失败？
A: 请检查网络连接和API密钥配置，确保通义千问服务可用。

### Q: 如何提高学情分析准确率？
A: 导入更多学生数据并训练模型，确保数据质量。

### Q: 可以导出哪些格式？
A: 目前支持Word文档导出，PPT和图片可直接下载。

### Q: 如何批量导入学生数据？
A: 目前需要逐个导入，后续版本将支持Excel批量导入。

## 注意事项

1. 首次使用需要注册账号
2. 生成资源需要一定时间，请耐心等待
3. 建议定期备份重要数据
4. 系统数据仅用于教学辅助，请妥善保管
